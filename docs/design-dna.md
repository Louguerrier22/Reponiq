# Interface design

[Documentation](README.md)

Reponiq uses a restrained dark neumorphic workspace: graphite surfaces, soft raised panels, inset text fields and lavender primary/selected controls. Green, amber and red communicate real status. Checked boxes use a lavender fill and dark check; unchecked boxes have a visible outline.

The shelf uses real repository cards with provider identity, branch, working changes and ahead/behind counts. Opening a project shows one focused workbench, without a second repository rail. Changes, commit history and GitHub pull requests are peer views. File diffs use readable green/red lines with line numbers and bounded scrolling.

At compact native sizes, navigation becomes an icon rail and actions wrap. The native minimum window width is760px. Labels, focus rings and keyboard operation remain available. The walkthrough points to current controls with a lavender ring; the underlying app remains sharp with no blur. It is skippable and replayable from Settings.

Motion stays short and task-local. Reduced motion disables it. Documentation images must be actual current app captures using disposable repositories, cropped to exclude private paths or account information. Generated concept art is not product documentation or verification evidence.
